# Coffee Meetups — Lahore Instagram launch plan

**Audience:** ages 20–28, Lahore  
**Primary channel:** Instagram only (Reels, Stories, feed, Meta ads)  
**Model:** company-hosted tables + third-party hosts on the same platform  
**Payments (Phase 1):** price shown in-app; collection off-platform (WhatsApp / bank transfer) after approval  
**Product:** Tables-first web app (request → host approve → Moments / chat)

Last updated: 2026-08-21

---

## 1. Goals (first 4 weeks)

| Goal | Target (directional) |
|------|----------------------|
| Signups from IG (Lahore) | 80–150 |
| Join requests on company tables | 40–80 |
| Paid / confirmed seats (WhatsApp) | 20–40 |
| Company tables that actually run | 4–6 |
| New external hosts approved (`canHost`) | 3–8 |
| Repeat attenders (2nd table) | ≥15% of attendees |

**Non-goals for this phase:** nationwide reach, in-app checkout, WhatsApp Business API automation, heavy follower-count vanity.

---

## 2. Positioning

### One-liner
> Small coffee tables in Lahore. Request a seat. Hosts approve. Pay after you’re in.

### Dual role (say this clearly)
1. **We host** — branded nights (“Coffee Meetups presents…”) for trust and content.  
2. **You host** — friends / creators run limited-seat tables; we provide discovery + requests.

### Price messaging (critical)
- Show **PKR amount** on the table (already supported).  
- Never imply card checkout in ads until it exists.  
- Use: *“After the host approves you, we’ll confirm payment on WhatsApp.”*

### Audience feel (20–28, Lahore)
- Board games, chill coffee, design/creative, uni/early-career, mixed friend circles.  
- Safety + approval culture is a feature, not a friction apology.

---

## 3. Funnel

```text
IG Reel / Story
  → Profile (bio link)
    → Login / signup (email OTP → password)
      → Featured / Discover (Lahore tables)
        → Request to join (+ code of conduct)
          → Host / ops approve
            → WhatsApp: pay + venue details
              → Attend → Moments content → next table
```

**Bio link options**
- Soft launch: single featured Lahore table URL.  
- Steady state: `/discover` or home with Featured Moments.  
- Always use UTM: `?utm_source=instagram&utm_medium=organic|paid&utm_campaign=lhr_w1`

## 4. Budget (Instagram / Meta ads only)

Assume ~280 PKR / USD (adjust to your rate).

| Phase | Spend | Rough PKR | Duration |
|-------|-------|-----------|----------|
| Week 1–2 test | $10–15 / day | ~3–4k / day | 10–14 days (~$150–200) |
| Week 3–4 scale winners | $15–25 / day | ~4–7k / day | 14 days (~$200–350) |
| **Month 1 total** | **~$350–550** | **~100k–155k** | Learning + soft fill |

**If budget is tighter:** $200–300 for month 1 (test only; fewer tables).  
**If budget is healthier:** $800–1,000 once one creative + one table convert.

### Spend split
| Bucket | % | Use |
|--------|---|-----|
| Guest acquisition | 70% | Reels → bio → request |
| Retargeting | 20% | 50%+ video views / site visitors |
| Host acquisition | 10% | “Host a table of 6” |

### Optimization targets (early)
- Optimize for **landing page views** first week, then **complete registration** / custom conversion if pixel is set.  
- Kill ads with CTR &lt; 0.6% or high bounce after 1–2k impressions.  
- Scale creatives that produce **join requests**, not just profile follows.

## 5. Pre-flight checklist (before paid ads)

- [ ] Prod email OTP works.  
- [ ] ≥2–3 Lahore tables live (company-hosted first).  
- [ ] Prices set; WhatsApp number + payment SOP ready (approve → invoice → confirm → seat).  
- [ ] Hosts gated (`canHost`); company account can host.  
- [ ] Featured Moments look good on mobile (Cover fit for reels).  
- [ ] Code of conduct + report path known to ops.  
- [ ] Meta Pixel (or at least UTM + manual tracking sheet).  
- [ ] Creative: ≥3 vertical reels from real nights (or strong phone footage).

## 6. Four-week calendar

### Week 1 — Soft proof (organic heavy, light ads)

**Ops**
- Publish 2 company tables (different vibes: e.g. board games + coffee & chill).  
- Staff WhatsApp evenings for approvals + payment.

**Organic (3–5 Reels)**
- Reel A: night energy collage / masonry Moments.  
- Reel B: “How it works” (30s): discover → request → approve → WhatsApp pay → cafe.  
- Reel C: host face / cafe pin (Lahore).  
- Daily Stories: seats left, polls (“Board games or deep chat?”), countdown.

**Paid**
- $10/day, Lahore, 20–28, interest: cafes / social / student-adjacent.  
- 2 creatives max; send to one table URL.

**KPI check (Fri)**
- Profile visits, link taps, signups, requests. Pause losers.

### Week 2 — Fill first tables

**Ops**
- Push incomplete tables; open waitlist voice in Stories if full.  
- Capture Moments from the first night (with consent).

**Organic**
- Recap reel within 24h of first meetup.  
- Guest POV Stories (repost with permission).  
- Highlight covers: *How it works*, *Lahore tables*, *Safety*, *Host*.

**Paid**
- Keep winners; add retargeting for viewers.  
- One table-specific ad with “X seats left · PKR Y”.

**KPI check**
- Confirmed payments / no-shows. Tighten WhatsApp script.

### Week 3 — Introduce “you can host”

**Ops**
- Approve 2–5 trusted hosts (friends / past guests).  
- One company table + 1–2 community tables.

**Organic**
- Host-facing Reel: “Host a table of 6 — we handle requests.”  
- Side-by-side: company night vs friend-hosted night.

**Paid**
- 90% guests / 10% hosts.  
- Slightly raise daily spend on winning guest creative only.

### Week 4 — Rhythm + decide

**Ops**
- Standing weekly slot (e.g. Sat evening Lahore).  
- Review reports / awkward payments; write internal FAQ.

**Organic**
- “This month in Lahore” montage.  
- Testimonials (text-on-reel if no face video).

**Paid**
- Double down or cut to organic-only based on cost per confirmed seat.

**Decision gate**
- Continue ads only if cost per **confirmed attendee** is acceptable to you (set your own ceiling, e.g. under ~PKR 1–2k acquisition before unit economics).

## 7. Sample ad / caption copy

### Guest — Reel primary text
> Lahore · 20s · small tables, not random crowds.  
> Request a seat → host approves → confirm on WhatsApp.  
> This week: Board games & chai · limited seats.

### Guest — headline / CTA
> Request your seat  
> Link in bio

### Guest — Story
> 3 seats left Saturday ☕  
> Reply “IN” or tap link — we’ll send the table.

### Host — Reel
> Host a Coffee Meetups table in Lahore.  
> You pick the cafe & vibe. People request. You approve.  
> We help you fill 4–8 seats — no mega-event chaos.

### Payment disclaimer (Stories / Highlights)
> Prices are listed on each table.  
> Payment is confirmed on WhatsApp after you’re approved — not charged in the app yet.

### Avoid
- “Pay now in app” / fake scarcity every day / stock footage only / “anyone can join instantly.”
